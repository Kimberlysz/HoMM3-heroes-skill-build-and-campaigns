HoMM3 heroes skill build and campaigns
==================

Hero skill-build notes for the Heroes of Might and Magic III:
The Shadow of Death campaigns. Bilingual (English / 中文).


WHAT'S INSIDE
-------------
HoMM3-heroes-skill-build-and-campaigns.yaml - one file, organised by campaign > scenario > hero.

For each hero you get:

  (0) specialty
  (i) main     - skills to take, aim for Expert
  (ii) backup  - situational picks / "keep but don't chase"
  (iii) avoid  - skills to refuse when offered

Inline comments (# ...) explain why a skill matters, e.g. which spells
Earth Magic unlocks. Checkboxes ([ ] / [x]) mark what the hero already
has in-game ("w/ game") or what you've picked so far.

HOW TO USE
----------
Open the .yaml in any text editor. Find your campaign and hero, then
follow "main" first - especially in the early maps, since level caps
and carry-over heroes (Gem, Crag Hack, Gelu, Yog) mean early choices
stick for the whole game.


CONTRIBUTING
